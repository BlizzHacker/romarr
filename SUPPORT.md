# Getting support

Use the [official ROMarr releases](https://github.com/BlizzHacker/romarr/releases) and [official Unraid listing](https://ca.unraid.net/apps/romarr-04jslct0riva81?q=romarr).

**ROMarrNG is a separate, independently maintained fork. This project does not provide support for that package.** See [official builds and support](docs/OFFICIAL-DISTRIBUTION.md) to identify your installation.

For an official build, [open an issue](https://github.com/BlizzHacker/romarr/issues) with your ROMarr version or commit, installation method, operating system, steps to reproduce, and the exact error. Remove API keys, passwords, cookies and private download links from logs.

Report a security problem privately using the process in [SECURITY.md](SECURITY.md).
