# UGREEN UGOS Pro

`docker-compose.yml` is a UGOS Pro Docker project. Setup steps are in [docs/NAS.md](../../docs/NAS.md#ugreen-ugos-pro).

- **Validation.** It's validated with `docker compose config`, and CI checks it. The library and downloads binds use `create_host_path: false`.
- **Store.** UGREEN's app center has no third-party submission.
